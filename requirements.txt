# Runtime dependencies: what a real install of the desktop app needs.
# (make install, build-windows.ps1/.bat, docs/SIGNING.md, and via
# requirements-dev.txt the CI release build.)
#
# The shared runtime pins live in requirements-core.txt; this file adds the
# tray/desktop backends on top. The resolved set is the same as before the split
# (#262) — tests/test_requirements_split.py pins that.
-r requirements-core.txt

# Tray icon (all platforms).
pystray>=0.19,<0.20

# Linux-only tray/desktop backends.
# PyGObject -> AppIndicator tray backend; python-xlib -> XOrg fallback backend
# (also the X11 foreground-window probe in src/sync/foreground_activity.py).
# Pin <3.50: PyGObject 3.50+ requires girepository-2.0 (libgirepository-2.0-dev);
# 3.48 builds against girepository-1.0, which is present on far more distros and
# keeps the bundled AppImage portable. PyGObject has no wheel and is COMPILED,
# which is why requirements-test.txt leaves this block out.
PyGObject>=3.42,<3.50; sys_platform == "linux"
python-xlib>=0.33,<1; sys_platform == "linux"
